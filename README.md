### What I'm building

**[wTerm](https://github.com/ddnazzah/wTerm)** — a desktop IDE for running many projects and many
persistent terminals at once. I built it for agent CLIs (`claude`, `aider`): backgrounded terminals
ring a native notification when they want input, agent sessions restore after a restart, and a
Tailscale-served PWA lets me attach to my live terminals from my phone.
*Electron 42 · React 19 · xterm.js · node-pty.*

**FlowVoice** — cross-platform AI dictation for the desktop. Rebuilding the transcription pipeline
around streaming cut end-to-end latency about 70%. *Electron · Bun.*

**Level Up** — a personal growth console for portfolio, career, learning and job search, fronted by
a daily AI briefing that reads my own numbers back to me. *Next.js · Postgres · Anthropic API.*
